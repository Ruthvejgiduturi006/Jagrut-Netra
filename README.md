🛡️ Jagrut Netra

Jagrut Netra( जागृत नेत्र ) is an AI-powered **Smart Surveillance System** built with **OpenCV + Streamlit**.  
It provides real-time monitoring and detection for various security and safety scenarios such as **crowd management, fire & smoke detection, restricted area monitoring, night security, and loitering detection**.

---

🚀 Features
- 🎥 **Crowd Management** → Detects and counts people in real-time.  
- 🔥 **Fire & Smoke Detection** → Identifies flames and smoke areas.  
- 🚫 **Restricted Area Security** → Alerts when an intruder is detected.  
- 🌙 **Night Time Security** → Provides monitoring in low-light/night conditions.  
- 🕒 **Loitering Detection** → Detects suspicious lingering movements.  
- 💾 **Recording Support** → Saves surveillance footage automatically.  
- 🎨 **Streamlit UI** → Modern, responsive web interface with custom styling.  

---

## ⚙️ Installation & Setup

1. **Clone the repository**
   
   git clone https://github.com/<your-username>/JagrutNetra.git
   cd JagrutNetra

3. **Install dependencies**

   pip install -r requirements.txt

4. **Run the Streamlit app**

   streamlit run app.py
